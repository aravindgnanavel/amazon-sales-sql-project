# Amazon Sales Analysis - SQL Project

## Project Overview
Analyzed Amazon Sales Dataset using MySQL Workbench to extract meaningful business insights.

## Dataset
- Source: Kaggle (Amazon Sales Dataset)
- Records: 1000+ rows
- Columns: Order ID, Order Date, Geography, Category, Product Name, Sales, Quantity, Profit

## Queries & Insights

### 1. Total Sales
- Calculated overall revenue from all orders
- **Result:** Total Sales = $10,189.26

### 2. Category-wise Sales
- Identified top performing product categories
- **Result:** 14 categories analyzed

### 3. Geography-wise Sales
- Analyzed sales performance by location
- **Result:** Los Angeles, California — Highest Sales

- MySQL Workbench 8.0
